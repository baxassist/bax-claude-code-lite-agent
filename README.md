# Bax Claude Code Lite

Плагин для Claude Code: задачи с телефона приходят прямо в **открытую вами сессию** Claude Code,
а ответы уходят обратно в мобильное приложение Бакса. Демон на весь компьютер не нужен —
канал живёт, пока открыт терминал, и видит только эту сессию.

Это второй, независимый способ работать с Claude Code из Бакса. Первый — движок
[bax-claude-code-agent](https://github.com/baxassist/bax-claude-code-agent): он сам запускает
Claude Code на компьютере и умеет больше (ресурсы машины, смена модели и сессий, «Стоп»).
Lite проще и безопаснее: Claude Code ведёте вы, плагин только передаёт задачи и ответы.

Устройство повторяет официальный плагин Telegram для Claude Code: тот же канал
`claude/channel`, тот же инструмент `reply`, тот же пересыл вопросов о разрешениях.

## Как подключить

1. В приложении Бакса: «Агенты» → «+» → **Claude Code Lite**. После создания на странице агента
   кнопка «Скопировать команду для Claude Code» копирует команду вида
   `/bax:connect <строка регистрации> <адрес сервера>`.
2. Один раз поставить плагин — в Claude Code:

   ```
   /plugin marketplace add baxassist/bax-claude-code-lite-agent
   /plugin install bax@baxassist
   ```

3. Запустить Claude Code в каталоге проекта с каналом Бакса:

   ```bash
   cd ~/projects/мой-проект
   claude --dangerously-load-development-channels plugin:bax@baxassist
   ```

   Флаг нужен, пока каналы Claude Code — исследовательская версия и своих плагинов в их
   списке нет.
4. Вставить в эту сессию скопированную команду `/bax:connect …`. Точка агента в приложении
   загорится зелёным — можно ставить задачи с телефона.

Дальше достаточно шага 3: регистрация запоминается за каталогом проекта.

## Что умеет

- задача с телефона — текстом (и надиктованная) — приходит в сессию;
- ответ модели уходит в приложение целиком;
- вопрос о разрешении — карточкой в телефоне: «Разрешить» или «Запретить»;
- состояние агента видно в приложении: не на связи, ждёт задачу, работает, ждёт вашего ответа;
- задачу можно поставить и закрыть приложение: открыв агента, вы увидите историю — плагин
  берёт её из файла сессии самого Claude Code (`~/.claude/projects/…/<сессия>.jsonl`), поэтому
  в ней и задачи с телефона, и ответы, и то, что вы писали прямо в терминале. Своей копии
  переписки плагин не держит, сервер Бакса — тоже. Вопрос о разрешении, пришедший без вас,
  покажется снова. Пока терминал закрыт, агент «не на связи» и истории нет — приложение
  подскажет, как его вернуть.

Остановка, смена модели и сессий — в терминале: Claude Code ведёте вы.

## Один агент — один проект

Строка регистрации привязывается к каталогу, где вы выполнили `/bax:connect`. Задача
с телефона всегда уходит в тот проект, которому её назначили, даже если открыто несколько
сессий в разных каталогах.

## Одна сессия на агента

Агента занимает сессия, подключившаяся первой. Вторая сессия в том же каталоге получит отказ
«агент занят» и подключится сама, когда первая закроется. Закрыли терминал — агент в приложении
«не на связи».

## Безопасность

- Регистрации лежат в `~/.bax/lite.json` с правами 600 — в файле секреты агентов, его не
  показывают и не пересылают.
- `/bax:connect` выполняется только по просьбе человека из терминала: сообщение, пришедшее
  через канал, подключить или перенастроить агента не может.
- Плагин не выполняет ничего сам: всё делает Claude Code вашей сессии, с её разрешениями.
- Строку регистрации можно в любой момент перевыпустить в приложении — прежняя перестанет
  работать сразу.

## Что внутри

| Файл | За что отвечает |
| --- | --- |
| `.claude-plugin/marketplace.json` | маркетплейс `baxassist` — отсюда `/plugin install bax@baxassist` |
| `plugins/bax/server.py` | MCP-сервер канала: задачи в сессию, `reply` и разрешения обратно |
| `plugins/bax/bax_link/` | протокол Бакса, соединение с сервером и история из файла сессии Claude Code |
| `plugins/bax/skills/connect/` | навык `/bax:connect` |
| `plugins/bax/.mcp.json` | запуск сервера: `uv run` с `mcp` и `websockets` |

Протокол и соединение лежат внутри папки плагина намеренно: Claude Code ставит плагин,
копируя его папку в свой кэш, и всё, что вне неё, туда не попадает.

## Что нужно

- Claude Code с поддержкой каналов (research preview) и подпиской Claude;
- [uv](https://docs.astral.sh/uv/) — им запускается сервер канала;
- аккаунт в Баксе (мобильное приложение).

## Тесты

```bash
uv sync
uv run pytest
```

Настоящий Claude Code в тестах не нужен: сессия и связь с Баксом подменяются, а проверяется
путь задачи с телефона в сессию и ответа обратно.
